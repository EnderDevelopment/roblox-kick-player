# KickPlayerScript

KickPlayerScript is a Roblox script designed to kick players from a Roblox game. It includes both a server-side script to handle the kicking functionality and a client-side GUI to allow administrators to input the player's name and initiate the kick. The script is useful for game moderators and administrators who need to manage their game's player base effectively.

## Install

1. Download the KickPlayerScript files from the GitHub repository.
2. Place the `kick_player_script.lua` file in the `ServerScriptService` of your Roblox game.
3. Place the `KickPlayerGUI.lua` file in the `StarterGui` of your Roblox game.

## Use

1. Open your Roblox game in Roblox Studio.
2. Navigate to the `ServerScriptService` and insert the `kick_player_script.lua` script.
3. Navigate to the `StarterGui` and insert the `KickPlayerGUI.lua` script.
4. Start playing your game.
5. As an administrator, open the Kick Player GUI from your player's screen.
6. Enter the name of the player you want to kick in the text box.
7. Click the "Kick Player" button to kick the specified player.
